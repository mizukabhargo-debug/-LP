# 陶雅 Google広告 検索キャンペーン設計書

低予算・ニッチ商材向けの検索広告プランです。Google広告管理画面にそのまま入力できる形で記載しています。

## 前提・予算

- ご要望: 2週間で合計 **¥12,000以内**
- 推奨1日予算: **¥800/日**(14日で¥11,200。予算超過を避けるためのバッファとして¥800を推奨)
- 入札戦略: **手動CPC(コンバージョン数の最大化などの自動入札は使わない)**
  - 理由: 自動入札はコンバージョンデータが一定数(目安20件/月以上)たまらないと最適化が効かず、少額予算では学習期間中に予算を溶かして終わるリスクが高いため。まずは手動CPCでクリック単価の上限を自分でコントロールする。
- 上限クリック単価(目安): **¥90〜120**からスタートし、表示回数が少なすぎる場合は¥150まで様子を見て調整
- キャンペーンタイプ: **検索キャンペーン**(ディスプレイ/P-MAXは低予算・低データでは不向きなため今回は対象外)
- 配信ネットワーク: 検索パートナーは**オフ**(品質の低いトラフィックを避ける)
- 地域: 日本全国(配送対応エリアが全国でない場合は要調整)
- 言語: 日本語
- デバイス: 除外なし(ただしモバイル比率が高い想定。LPのモバイル表示を優先確認)

## キャンペーン構成

```
キャンペーン: 陶雅_ペット肖像画_検索
└ 広告グループ: ペット肖像画_陶器ギフト
```

広告グループは予算が少ないうちは**1つに絞る**ことを推奨します(分散させるとどちらのデータも薄くなるため)。

## キーワード(フレーズ一致・絞り込み中心)

低予算では「部分一致」は無関係な検索にも配信されて予算を消費しやすいため、**フレーズ一致**を中心に設定してください。

```
"ペット 肖像画 陶器"
"犬 肖像画 プレゼント"
"猫 肖像画 オーダーメイド"
"ペット イラスト 器"
"愛犬 メモリアル ギフト"
"ペット 遺影 オーダーメイド"
"犬 猫 似顔絵 皿"
"陶器 ペット 絵付け"
"オリジナル 食器 ペット"
```

最初は上記から**5〜6個**に絞って開始し、検索語句レポートを見ながら追加してください(全部入れると予算が分散します)。

### 表示URL・リンク先URL

- リンク先URL: LP公開後のトップページURL(例: `https://mizukabhargo-debug.github.io/-LP/`)+ 計測用UTMパラメータ

  - ※Google広告の自動タグ設定(gclid)を有効にしていればUTMがなくてもGA4側で計測可能ですが、念のため両方設定することを推奨します。

## コンバージョン計測

1. GA4プロパティを作成し、測定ID(G-XXXXXXXXXX)を `js/config.js` の `GA4_MEASUREMENT_ID` に設定
2. Google広告アカウントでコンバージョンアクションを2つ作成(正方形購入・長方形購入)
   - 目標のカテゴリ: 購入
   - 値: 各サイズの税込価格(¥77,000 / ¥143,000)を固定値として設定
   - コンバージョンID(AW-XXXXXXXXX)とラベルを `js/config.js` に設定
3. `thanks-square.html` / `thanks-rect.html` はStripe決済完了後のリダイレクト先として、ページ到達時に自動でコンバージョンを計測します(コード実装済み)

## 運用スケジュール(2週間)

| 期間 | やること |
| --- | --- |
| 開始〜3日目 | 配信開始。表示回数・クリック数を毎日確認。極端にクリック単価が高い/表示回件数が0のキーワードは停止 |
| 4〜7日目 | 検索語句レポートを確認し、無関係な検索語句を除外キーワードに追加 |
| 8〜14日目 | クリック率(CTR)の高い見出しを確認し、低い見出しを差し替え。予算消化ペースを再確認し¥12,000以内に収まるよう日予算を調整 |

## 低予算での現実的な期待値

- 想定クリック単価: ¥50〜150(ニッチ商材のためCPCは比較的低めと想定していますが、実測値ではなく推測です。実際の相場は配信開始後に確認してください)
- ¥11,200 ÷ ¥100(想定平均CPC)= 約112クリック程度が2週間の目安
- 高単価商品(税込7〜14万円)のため、コンバージョン(購入)は少数(0〜数件)にとどまる可能性が高いです。この段階の目的は**購入獲得より、LPへの反応(クリック率・滞在時間・フォーム到達率)を見るテスト**と位置づけることを推奨します。
